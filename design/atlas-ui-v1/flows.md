# My Little Atlas · 页面与动线索引

2026-11-07 · 56 个页面／状态 · 390 × 844 设计画布 · 2× PNG 导出。

## 主动线

收藏首页 → 新增 → 导入 → 核对分店 → 明确勾选 → 收藏完成 → 地图 → 地点详情 → 记录到访 → 保存 → 手账 → 海报模板 → 预览 → 保存／系统分享。

## 状态约定

- 想去：没有到访记录；去过：至少一条正式到访；再去：去过后的独立意愿标签。
- 同一地点可加入多个收藏夹，多次到访挂在同一地点。
- 导入结果首次不预选；截图展示已经主动选中两项的中间状态。
- 草稿不计入到访，导航与定位不触发自动打卡。
- 无坐标地点进入待定位，不放置误导地图标记。
- 照片、地址、距离、统计为演示内容；地图为非地理示意。
- 账号与云同步为后续能力；本机 JSON 备份不含照片。

## 查看方式

双击 index.html 打开完整画廊，可按功能组筛选。点击「体验完整动线」或页面按钮进入单页预览。业务数据为静态示例，搜索、导入、导航、登录与分享未连接真实服务。boards 目录含核心总览与 13 张功能分组图，screens 目录含全部独立页面。

## 制作方式

使用本地 HTML/CSS 排版，由浏览器渲染 PNG，保证中文与组件一致。照片复用项目已有素材；上海城市封面裁自用户参考图，仅用于本轮设计展示。未调用图像生成 API，未修改 Kotlin App。
