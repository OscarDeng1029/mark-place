## 核心动线

收藏首页 → 新增 → 导入灵感 → 核对分店 → 确认选择 → 收藏完成 → 地图 → 地点详情 → 到访记录 → 生成手账 → 选择分享模板 → 检查隐私 → 保存或系统分享。

## 页面结构

底部五个入口为「收藏 / 地图 / ＋ / 足迹 / 我的」。城市图鉴从足迹进入，低频的足迹日记保留在「足迹」，不与收藏首页混为一个入口。

一个地点可以在多个收藏夹中。没有到访的是「想去」，至少有一次正式到访的是「去过」；「再去」为可关闭的意愿标签，可与去过并存。地图只显示用户收藏且地址已定位的地点。导入结果必须由用户明确挑选；相同地点会追加到已有条目，不重复建店。导航或开启定位都不会自动记录到访。

## 图像说明

PNG 由浏览器对 HTML/CSS 页面直接渲染，保持中文清晰和跨页组件一致。咖啡、书店和甜品照片复用项目已有氛围素材；上海城市封面裁自用户参考图，仅用于本次设计展示。店名、地址和统计为演示内容，地图为示意插画，不对应真实地理位置。本轮未调用图像生成 API，也没有修改 Kotlin 原生 App。

账号登录与云同步页面标明为后续能力；本机 JSON 备份不含照片原文件。系统分享、照片选择、地点识别等在本稿中用于展示交互状态，不会联系真实服务或外部应用。
