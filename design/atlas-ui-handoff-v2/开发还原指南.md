## 哪些用图片，哪些用组件

|元素|实现方式|理由|
|---|---|---|
|地点照片、城市照片|可替换图片|照片是内容；目前为已有照片与参考图裁片占位|
|纸纹、撕边纸、相框、胶带|独立 PNG，按逻辑尺寸叠加|保留细微不规则边缘和手账质感|
|勋章、猫咪涂鸦、装饰印章|透明 PNG|保留参考图手绘语言；勋章名称与进度另画|
|标题、日期、数值、地点名、描述|原生文字组件|支持编辑、搜索、国际化与辅助功能|
|按钮、输入框、选择状态、列表、弹层|原生交互组件|点击范围、键盘、状态变化必须有效|
|线性操作图标|`assets/icons/` 的 SVG 或匹配矢量|保持清晰；可使用主题色|
|地图|真实地图 SDK + 原生标记|预览是示意地图，不能用于真实导航|

不要把整页 PNG 作为可操作页面。截图仅作视觉验收基准；照片和装饰可以替换，不影响用户文字与按钮。

## 坐标、缩放与旋转

- JSON 的 `canvas`、`layoutBox`、`viewportBounds` 均为 1× 逻辑单位；不要把 3× PNG 像素当作 dp。
- `layoutBox` 是局部、未旋转的布局尺寸，`offsetParent` 指定其布局坐标来源。`parent` 另记录 DOM 层级，二者可能不同。
- `viewportBounds` 是应用祖先变换后的轴对齐外包框，只用于核对屏幕占位；旋转过的外包框不是原始宽高。
- `style.transform` / `transformOrigin` 和 `imageLayers.transformChain` 指定旋转与变换中心。照片、相框在同一父容器内共同旋转；胶带可以再相对旋转一次。
- `order` 是文档遍历顺序，不是完整绘制顺序。叠放还需结合 `zIndex`、父级变换与堆叠上下文；预览与分层图是最终参照。
- 参考宽度为 390。正常用弹性布局重排；照片保持定义比例，避免为了适配较宽设备横向拉伸所有文字。
- `scrollContainers` 记录可视框、内容高度与初始滚动位置。截图和 `viewportBounds` 对应初始视口，屏幕外内容不能因截图没展示就删掉。
- 顶部 43、底部指示区 21 是设计预览的系统区域。实机使用系统安全区，状态栏和手势条不烘焙成图片。

## 照片组件与素材叠放

从底到顶：纸张背景 → 照片内容框 → 透明相纸框 → 胶带 → 可变标题／注释 → 交互控件。印章中图案与环为图片，文字单独绘制。

|组件|外框逻辑尺寸|照片窗口 x / y / 宽 / 高|
|---|---|---|
|wide|344 × 233|6 / 6 / 332 / 203|
|thumb|140 × 150|7 / 7 / 126 / 118|
|small|135 × 128|6 / 6 / 123 / 104|
|portrait|180 × 210|8 / 8 / 164 / 174|

以上是组件标准尺寸；具体页面若有缩放，以该页 JSON 中图片节点尺寸为准。欢迎页有 177 × 211 的实际外框，按页面实际内边距定位。

照片用 cover / `ContentScale.Crop` 居中裁切，计算为 `scale = max(窗口宽/原图宽, 窗口高/原图高)`，超出窗口的部分裁掉。默认锚点为 `(0.5, 0.5)`；若替换照片主体偏离中心，先调整该素材焦点再更新页面规格。相框 PNG 的中间是真实透明，不能用不透明白矩形盖住照片。

- 相框不烘焙旋转、阴影或文字；旋转与柔和阴影由容器完成，详情见每页的 `style.boxShadow` / `filter`。
- 胶带基础尺寸 88 × 22，PNG 已含半透明度，不要再次统一降为 0.6。页面会按具体尺寸缩放、旋转。
- 纸纹 `paper_cream_tile.png` 按 192 × 48 逻辑单位重复平铺，不拉伸成一整张屏幕。
- 撕边纸基础 210 × 130，预览按容器拉伸；更长文案建议九宫格伸缩，四边保护 8 逻辑单位，避免拉坏纸边。改用九宫格后需另做视觉对齐。
- 未解锁勋章用同一 PNG 做灰度和透明度处理，不要生成第二套低清截图。当前预览为约 92% 灰度、34% 不透明度。
- `assets/` 中的 1× / 2× / 3× 是独立导出文件。Compose 示例推荐取 @3x，重命名为合法资源名后在代码明确指定 dp，不能按图片像素默认测量。

## 字体与颜色

`specs/design-tokens.json` 是本轮 V2 视觉基准。原项目主题色与 V2 存在差异，开发时应明确采用 V2 令牌，避免一半沿用旧色一半新色。本轮未更改原生 App。

`assets/fonts/atlas_serif.ttf` 随 OFL 授权文件提供。预览的中文正文使用本机 Microsoft YaHei，部分手写文字使用 KaiTi，二者未打包、不可视为已获分发许可。实机需选择有许可的中文正文字体／手写字体；字体未匹配前，换行与字宽不能宣称像素完全一致。

## 照片与高清替换

完整提示词见 `生成图片提示词.md`。先生成外观、室内、咖啡桌面三张，保持同一家虚构店；再补甜品、书店、街景。可选城市远景和四枚高清贴纸。每张单独输出；照片不包含相框、文字、胶带或 UI。

现有七张照片为过渡素材，不是一套同店实拍。街景 123 × 95、城市远景 119 × 117，以及约 60–80 像素的参考贴纸，受原图清晰度限制；@3x 是重采样，不会产生新细节。`specs/asset-manifest.json` 记录来源、裁切、真实像素、逻辑尺寸、哈希和替换状态。

保留用户生成原图，放入 `incoming/`，采用提示词规定文件名。替换时更新对应资产与清单，重新执行 `scripts/export-handoff.cjs` 导出效果图和图层规格，避免交付旧图。参考图与已有照片目前仅作设计原型来源，上线前确认使用权。

## 交互验收要点

- 收藏、去过、还想来保持不同含义；还想来是额外标记，草稿不算到访。
- 导航不会自动记为到访；到访记录需用户确认保存。
- 同一地点可以属于多个收藏夹，同一地点也可以有多次到访。
- 灵感导入默认不勾选；当前演示有明确的已选择状态，保存只作用于用户选中的地点，重复项应合并。
- 代码层保留 JSON 的 `action` 去向和页面入口；装饰图片不拦截点击，不进入无意义的屏幕阅读顺序。
- 在参考 390 宽设备和至少一个更小设备验证文字、滚动、安全区、按钮；同时检查中文长名称和无照片状态。
