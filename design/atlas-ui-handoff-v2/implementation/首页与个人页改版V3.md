## 栏目职责

|栏目|用户目的|主要呈现|
|---|---|---|
|手账（首页）|翻看生活、回忆一次到访、想起下一站|一本横向翻阅的纸质手账；扉页、待出发清单、每次到访独立内页|
|地图|找地点、挑下一站、导航|真实底图、筛选与地点卡|
|＋|快速新增|导入、手动添加、记录到访|
|收藏|查找与整理心动地点|原有收藏夹/搜索/筛选/批量整理；承担工具型列表功能|
|我的|这本手账属于谁、保存哪些个人积累|布纹封底、署名纸、个人封面小照片、城市护照印章、错落票根、成就贴纸、草稿口袋和设置|

足迹时间线从首页右上“足迹索引”和个人页到访票根进入，功能保留。

## 手账首页

- 第1页生活扉页：日期与标题、大相纸、最近到访便笺、下一站便条、两张不对齐票根；取消三列等距统计和收藏夹网格。
- 第2页待出发：未到访地点的错位照片和愿望便笺，入口直达地点/地图；空库提供添加入口。
- 后续按实际到访倒序一条一页。使用三组稳定排版，变化照片位置、尺寸、角度、便笺方向和票根；不会每次重进随机乱排。
- 每页有独立页码；可左右滑动，也可按前/后按钮。横滑采用透视倾斜与明暗变化，目前为翻页式浏览动效，未实现纸张卷曲的物理仿真。
- 切到别的底栏再回来保留当前页。首页正文均来自现有数据，长文本预览省略，点击展开完整记录；不伪造故事或统计。

## 我的封底

- 身份信息用署名纸与小封面照，不再使用首页那样的全宽大图和三列统计。
- 同一数据改为城市圆章、到访纪念票和收藏收据；“留下足迹的城市”按真实去过的城市算，区别于全部收藏城市。
- 勋章错落摆放，未解锁继续灰化；设置、资料编辑、草稿、分享和原有持久化逻辑不变。
- 页面装饰使用现有资源与原生绘制，没有调用生图/付费API；待生成素材仍可在集中映射处替换。
