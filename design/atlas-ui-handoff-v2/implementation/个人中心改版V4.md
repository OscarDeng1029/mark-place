# 个人中心改版 V4

> 历史方案，已停用：用户明确“不是这版，再上一版”，当前恢复的是封底之前的原 ProfileV2（大封面、圆头像、三列数据和勋章）。请以 个人页恢复首版.md 为准。

2026-11-07。用户要求：“我的页面可以不用手账风格，用一眼能看清楚的风格，只有手账页面用手账风格就可以了。”

## 页面分工

- 手账：保留 V3 横向翻页、纸纹、胶带、便笺、错落照片和到访回忆。
- 我的：改为标准个人中心，纯色背景、白色卡片、整齐对齐、常规字体；取消布纹封底、撕纸署名、票根、印章和不规则堆叠。
- 收藏和地图：保持功能型浏览，收藏夹去胶带、封面编辑改为普通照片；地图标记保持正向。全局纸纹不再默认开启，仅手账首页和手账详情启用。

## 信息顺序与入口

1. 顶部“我的”标题和设置按钮。
2. 资料卡：头像裁切、昵称、签名、明确“编辑个人资料”入口，整卡可点。
3. 数据统计：收藏地点、到访记录、探索城市；均可进入对应页面。探索城市只计实际到访城市。
4. 我的内容：我的收藏夹、足迹记录、城市图鉴、我的勋章；右侧显示数量，行尾固定方向指示。
5. 管理与分享：草稿箱、分享我的图鉴、设置与备份。
6. 页脚：数据保存在此设备。

每行点击区域最小 58dp，长昵称与签名按行数截断。窄屏允许纵向滚动，宽屏内容居中且最大宽度 620dp。
