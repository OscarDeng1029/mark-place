# 简化动线与城市分类落地

更新：2026-11-08。原生源码版本：`44d2931`。Android、iOS 和桌面共用 Kotlin Compose 页面。

## 当前行为

- 手账首页直接打开最近的一篇到访记录，按日期翻页；切换底部导航后保留页码。无照片的实际记录显示文字便笺。
- 右上角「目录」在当前手账内打开底部面板。先按城市筛选，再按月份查看；支持搜索地点、日期和正文。点击记录直接翻到全本手账中的对应页。
- 目录只列有到访记录的城市。收藏则按收藏地点所在城市分类，同页组合「全部 / 想去 / 去过」。不足两座城市时隐藏城市分类，避免多余操作。
- 「＋」只提供「写手账 / 收藏地点」。写手账可直接填写新地点和城市，日期默认为设备今天，照片与文字选填。保存后直接展示生成的一页。
- 尚未收藏的新地点也可存草稿、继续写；保存草稿时不会提前创建地点或到访。正式保存时，地点、记录与草稿移除一并写入，失败时保留原状态。
- 手账页标题与正文现在是两个独立字段。旧记录没有标题字段时，编辑页会把原正文第一行带入标题、剩余内容带入正文；保存后不再依赖正文第一行，也不会丢失旧文字。
- 「我的」保留用户选定的 ProfileV2 大封面、圆头像、昵称签名、三列统计、勋章与功能列表。手账入口回到首页，去过的城市在地图查看，城市数按实际到访统计。
- 收藏夹与批量整理保留在收藏页次要入口。链接导入、系统分享和原地图功能继续使用既有实现。
