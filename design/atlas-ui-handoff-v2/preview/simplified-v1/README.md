# 上手与入口简化 · 第一版效果原型

打开 [index.html](index.html) 即可交互。使用同项目已有照片、字体、纸张、胶带和贴纸；不需要网络、登录或生图 API。

本轮交付是供用户评审的效果与动线原型。原生 Android / iOS 页面及用户记录没有在本轮变更。预览中的编辑、保存、草稿和个人资料修改仅保存在当前页面内存，刷新后恢复示例内容。

## 主要变化

1. 手账首页直接展示最近一篇真实记录的样式；取消强制翻过的扉页、心愿清单与重复统计。
2. 「足迹索引 → 我的足迹」合并为当前手账的「目录」底部面板。可搜索地点、日期与文字，点击直接翻到对应页。
3. 中间的「＋」只保留「写手账 / 收藏地点」两个动作。
4. 写手账可以直接填写新地点，无需先收藏；日期默认为当天，照片与文字选填。保存即返回生成的页面。
5. 首次使用只展示空白手账与主按钮「写下第一篇手账」，附次要入口「先收藏一个想去的地方」。
6. 收藏按「全部 / 想去 / 去过」筛选；收藏地点不自动产生到访记录。
7. 城市汇总并入地图；个人页的「去过的城市」和地点数量只按已记录到访统计。
8. 个人页沿用用户最终选定的大封面、圆头像、三列数据、勋章和功能列表，不另做一套新外观。记录入口回到同一本手账，城市入口直达地图的「去过」筛选。

手账翻页页码在切换底栏后保留；可用左右箭头、键盘左右键或在纸页上横向拖动翻页。浏览器中支持填写地点、选择示例照片或设备照片、保存并编辑记录、存草稿再继续写、收藏地点、资料编辑。
