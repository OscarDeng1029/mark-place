# 手账排版优化 · HTML 预览 04

双击 [index.html](index.html) 可在浏览器交互，不需要安装依赖或联网。当前只交付网页预览，未修改 Android、iOS 或用户记录。

## 设计判断

用户上传的画幅影响布局建议。默认保留原图比例，允许相纸和文字便笺少量遮住边缘；轻点照片可以在调整窗口看到完整原图，手动裁切时才提供目标画幅、位置与缩放。预览读取图片尺寸，没有调用 AI 或声称自动识别人脸、主体。所有排版均支持横图、竖图和方图，也支持用户覆写排列方式。

参考真实相纸手账的摆放方式：纸张微微错位，照片边缘贴胶带，日期和照片编号留在相纸白边；票根与邮戳留在边缘，文字分别写在便利贴、撕纸、剪报和横线纸上。装饰由现有本地素材与 CSS 绘制，无新增生图素材。

## 本版变化

- 顶部「我的手账」栏从现有 App 的 76dp 对应调整为预览中的 49 CSS px；日期、小记标题和地点区更紧凑。照片、文字和小装饰现在共用约 502px 高的整页构图区域。
- 七种风格：随手一贴、双影拼贴、旅途明信片、胶片散页、旅途采集、纸上留白。照片张数不被强制补齐，仅一张时显示单图。
- 双图宽度从大约半页增到七成至九成页宽，采用错位交叠；默认示例的两张照片总面积超过上一版两列摆放的两倍。照片边角叠放，前后层次可以交换。
- 文字不再固定放在底部：双影拼贴是右上方形便利贴，胶片散页是左下剪报，旅途采集是左上切角纸笺。文字载体（便利贴、撕纸、剪报、横线纸）和形状（方形、纸条、切角）可分别切换。
- 照片滑动后，重新按画幅组合。原比例保留，手动裁切仍可用；用户也可切换回左右或上下排列。
- 印章直径 64px，沿前景照片露出的边缘择位。逐个候选位置计算与两张照片的圆形重叠面积，并避让文字与底部操作；覆盖小于一半。交换前后和切换照片后也重新定位。照片计数与调整按钮会避开被纸条或前景照片盖住的角落。
- 每个相框可独立左右滑动，循环查看整组照片；滑动不会误翻整页。轻点照片进入构图调整，裁切设置按相框和照片分别记住。取消保留原设置，可随时恢复完整照片。
- 「方形留影」默认使用 1:1 满版裁切，让照片本身成为正方形；在构图调整中切换「完整显示」即可恢复原图比例。
- 裁切预览与最终照片框使用一致的目标比例；支持横幅、竖幅、方形、拖动位置和缩放。
- 可上传本机多张照片测试。仅在当前浏览器内存中读取，不发送到服务器；关闭或刷新后不保留。

## 查看方式

- `index.html`：含样式、照片、排列方式、前后交换、纸张与纸张形状切换的交互工作台。
- `index.html?view=board&set=double`：本轮三种交叠双图排版的对照。
- `index.html?view=board`：七种排版的完整对照。
- `index.html?single=1&style=duo`：纯手机单屏；`style` 支持 `daily / duo / square / postcard / film / collect / quiet`。
- [交叠双图对照](exports/overlap-double-layouts.png)、[七种排版长图](exports/seven-layouts.png)、[交互工作台](exports/interactive-preview.png)。

页面中的文字与图片均为预览示例，不会加入真实手账。翻页箭头和键盘左右键在网页中切换排版示例；目录列出这七个预览页。地图、收藏、我的仅展示现有底栏的位置，不模拟这些页面。

## 验证

在项目根目录运行：

```powershell
& 'design/atlas-ui-v1/.tools/node-v22.14.0-win-x64/node.exe' 'design/atlas-ui-handoff-v2/scripts/verify-journal-v3.cjs'
```

使用项目现有 Playwright 与 Edge。检查七种风格 × 三种照片组合的原图比例、照片交叠、放大面积、文字的位置和方形比例、旋转后的实际圆形印章覆盖范围、前后交换、四种纸张和纸张形状、手动排列、独立照片滑动、构图保存与取消、上传读取真实尺寸、4:1 超宽图完整展示和 375px 手机宽度。详细结果在 [verification.json](exports/verification.json)。

正式接入 App 时，需要把原图尺寸、每个照片槽的选择、完整/裁切状态、目标比例、焦点与缩放保存到记录中；缺少这些字段的旧记录默认完整显示。本轮只在 HTML 内存中演示这些行为。
